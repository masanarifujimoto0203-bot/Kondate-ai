# 献立AI - Netlify公開手順

## 📁 ファイル構成
```
meal-planner/
├── index.html      ← メインのアプリ
├── manifest.json   ← PWA設定
├── sw.js           ← オフライン対応
└── icon.svg        ← アプリアイコン
```

---

## 🚀 STEP 1：GitHubにアップロード

1. https://github.com にアクセス、アカウント作成（無料）
2. 「New repository」をクリック
3. リポジトリ名：`kondate-ai`
4. 「Create repository」
5. 「uploading an existing file」からフォルダ内の全ファイルをドラッグ＆ドロップ
6. 「Commit changes」をクリック

---

## 🌐 STEP 2：Netlifyで公開

1. https://netlify.com にアクセス、GitHubでログイン（無料）
2. 「Add new site」→「Import an existing project」
3. GitHubを選択 → `kondate-ai` リポジトリを選択
4. 設定はそのままで「Deploy site」をクリック
5. 数分で `https://ランダム名.netlify.app` のURLが発行される！

---

## 📱 STEP 3：iPhoneのホーム画面に追加

1. Safariで発行されたURLを開く
2. 下部の「共有」ボタン（□↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 「追加」をクリック
5. ホーム画面に「献立AI」アイコンが追加される ✅

---

## ⚙️ 重要：APIキーの設定

現在のコードはAnthropicのAPIを直接呼び出しています。
本番公開前に必ずバックエンドを挟んでAPIキーを隠してください。

### 簡単な方法（Netlify Functions）

`netlify/functions/suggest.js` を作成：

```javascript
exports.handler = async (event) => {
  const { prompt } = JSON.parse(event.body);
  const res = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": process.env.ANTHROPIC_API_KEY,
      "anthropic-version": "2023-06-01"
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-20250514",
      max_tokens: 1000,
      messages: [{ role: "user", content: prompt }]
    })
  });
  const data = await res.json();
  return { statusCode: 200, body: JSON.stringify(data) };
};
```

Netlifyの「Environment variables」に `ANTHROPIC_API_KEY` を設定するだけでOK。
